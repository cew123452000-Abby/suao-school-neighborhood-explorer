# 蘇澳國小｜我的學校附近有什麼？

適合國小學童操作的社區探索互動遊戲。學生可選擇四張蘇澳國小附近地圖，加入建築、自然環境、生活設施、商店與交通設施，完成探索任務後輸入姓名並下載含有自己地圖作品的證書。

## 功能

- 四張蘇澳國小附近地圖
- 42 種可拖曳、可觸控加入的地點物件
- 臺灣繁體中文與直式注音，聲調標示於注音右側
- 地點觀察紀錄與探索任務
- 地圖圖片下載
- 完成任務後產生個人探索證書
- 支援手機、平板與電腦

## 使用方式

直接開啟 `index.html`，或使用 GitHub Pages 線上操作。

> 教學提醒：請勿在觀察紀錄中填寫住址、聯絡方式或其他個人資料。
